This folder contains UI automation examples focused on validating critical user flows in the Insurance Policy Management System.

Automation Focus:
- Login flow validation
- Policy creation workflow
- Form validation scenarios
- Navigation and UI stability checks

Objectives:
- Ensure core user journeys work consistently
- Detect UI regressions early
- Validate frontend behaviour across scenarios

Approach:
- Prioritised stable and repeatable flows
- Focused on regression-prone areas
- Designed tests to be reusable and maintainable

Future Improvements:
- Page Object Model structure
- CI/CD integration
- Cross-browser execution
