# Online Insurance Policy Management System — UAT Simulation
**QA Portfolio Project | 2026 (In Progress)**

## Project Overview
This system simulates an online insurance policy management workflow to demonstrate User Acceptance Testing (UAT) processes.  
- **Customers** can register/login, browse insurance plans, purchase policies, view dashboards, and submit claims.  
- **Admins** can approve or reject claims and monitor all policies.  

**Real-world problems addressed:**
- Eliminates manual tracking of policies and claims.  
- Reduces delays and errors in claim approvals.  
- Ensures data accuracy and transparency in customer transactions.  
- Provides a digital workflow that reflects real business requirements.
